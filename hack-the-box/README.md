## 🧠 What I'm Learning

HTB Academy is teaching me the "why" behind the tools, not just the "how". I am focusing on:

- **Methodology:** Following a strict process (Recon → Enumeration → Exploitation → PrivEsc).
- **Enumeration:** Learning not to rush, and to check _everything_ (ports, services, web directories, hidden files).
- **Documentation:** Taking detailed notes and screenshots as I go, so I can write professional reports.
- **Tool Proficiency:** Moving beyond script-kiddie usage to understanding how tools like Nmap and Metasploit actually work under the hood.
