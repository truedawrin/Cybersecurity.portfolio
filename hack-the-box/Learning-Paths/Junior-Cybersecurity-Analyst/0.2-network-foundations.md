## 🕵️‍♂️ Hands-On: Networking Fundamentals

### 🔎 Conceptual Breakdown

This module focused on building a robust understanding of how networks function, from the physical layer up to application-level services.

**1. What is a Network?**

A network is a collection of interconnected devices that can communicate — sending and receiving data, and sharing resources with each other. Key concepts include:

- **Nodes:** Individual devices connected to a network (computers, smartphones, printers, servers).
- **Links:** Communication pathways that connect nodes (wired or wireless).
- **Data Sharing:** The primary purpose of a network is to enable data exchange.

**Why Networks Matter:**

- **Resource Sharing:** Multiple devices can share hardware (like printers) and software resources.
- **Communication:** Instant messaging, emails, and video calls rely on networks.
- **Data Access:** Access files and databases from any connected device.
- **Collaboration:** Work together in real-time, even when miles apart.

**2. Types of Networks**

| Characteristic         | LAN (Local Area Network)          | WAN (Wide Area Network)                     |
| :--------------------- | :-------------------------------- | :------------------------------------------ |
| **Geographical Scope** | Small area (home, school, office) | Large area (cities, countries, continents)  |
| **Ownership**          | Single person or organization     | Multiple organizations / ISPs               |
| **Speed**              | High data transfer rates          | Slower compared to LANs                     |
| **Media**              | Ethernet cables, Wi-Fi            | Fiber optics, satellite links, leased lines |
| **Maintenance**        | Easier and less expensive         | Complex and costly                          |
| **Example**            | Home or office network            | The Internet                                |

**How LANs and WANs Work Together:**
A home LAN connects to an ISP's WAN to access the Internet. A modem acts as a bridge between the home network and the ISP's infrastructure, converting digital signals for transmission over various media. In business settings, companies link multiple office LANs via WANs for unified communication and collaboration across geographic locations.

**3. Networking Models**

The OSI (Open Systems Interconnection) and TCP/IP models provide frameworks for understanding how data travels across a network. These models break down the complex process of network communication into distinct layers, each with specific responsibilities.

**4. Key Network Components**

| Component        | Role                                                               |
| :--------------- | :----------------------------------------------------------------- |
| **Router**       | Connects different networks and directs traffic between them.      |
| **Switch**       | Connects devices within the same network (LAN).                    |
| **Firewall**     | Filters incoming and outgoing traffic based on security rules.     |
| **Server**       | Provides services or resources to other devices (clients).         |
| **Modem**        | Converts digital signals for transmission over ISP infrastructure. |
| **Access Point** | Provides wireless connectivity to a wired network.                 |

**5. Addressing and Ports**

| Concept         | Description                                                                 |
| :-------------- | :-------------------------------------------------------------------------- |
| **MAC Address** | Physical hardware address of a network interface (Layer 2).                 |
| **IP Address**  | Logical address for a device on a network (Layer 3).                        |
| **Ports**       | Logical endpoints for specific services (e.g., 80 for HTTP, 443 for HTTPS). |

**6. Address Resolution Protocol (ARP)**

ARP is used to map an IP address to a MAC address on a local network. When a device wants to communicate with another device on the same LAN, it needs the MAC address. ARP broadcasts a request ("Who has this IP?") and the device with that IP responds with its MAC address.

**7. Network Data Flow Process**

Data travels through the network layers in a process called encapsulation (as it moves down the stack) and de-encapsulation (as it moves up the stack on the receiving end). Each layer adds its own header with control information.

**8. DHCP and the DORA Process**

DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses to devices on a network. The DORA process:

- **D**iscover: Client broadcasts to find a DHCP server.
- **O**ffer: Server offers an available IP address.
- **R**equest: Client requests the offered IP.
- **A**cknowledge: Server confirms the assignment.

**IP Address Leasing:** IPs are leased for a specific duration. When the lease expires, the client must renew it or receive a new one.

**9. NAT and PAT (IP Address Conservation)**

| Technique                             | Description                                                                   |
| :------------------------------------ | :---------------------------------------------------------------------------- |
| **NAT (Network Address Translation)** | Maps multiple private IPs to a single public IP.                              |
| **PAT (Port Address Translation)**    | Maps multiple private IPs to a single public IP using different port numbers. |

**10. DNS and DNS Hierarchy**

DNS (Domain Name System) translates human-readable domain names (e.g., `example.com`) into IP addresses. The DNS hierarchy includes:

- **Root Servers:** The top of the DNS hierarchy.
- **TLD Servers:** Top-Level Domain servers (e.g., `.com`, `.org`).
- **Authoritative Servers:** Hold the actual DNS records for a domain.

**DNS Resolution Process:** The resolver queries root → TLD → authoritative servers to find the IP address.

**11. Internet Architectures, Wireless Networks, and Mobile Hotspots**

- **Internet Architecture:** The global network of networks that connects billions of devices.
- **Wireless Networks:** Use radio frequencies to transmit data (Wi-Fi).
- **Mobile Hotspot:** A device that shares its cellular data connection with other devices via Wi-Fi.

**12. CIA Triad Applied to Network Security**

| Pillar              | Network Security Application                 |
| :------------------ | :------------------------------------------- |
| **Confidentiality** | Encryption (TLS/SSL), VPNs, access controls. |
| **Integrity**       | Hashing, digital signatures, checksums.      |
| **Availability**    | Redundancy, DDoS protection, load balancers. |

**13. Firewalls, IDS, and IPS**

| Security Control                      | Purpose                                      |
| :------------------------------------ | :------------------------------------------- |
| **Firewall**                          | Filters traffic based on rules (allow/deny). |
| **IDS (Intrusion Detection System)**  | Detects suspicious activity and alerts.      |
| **IPS (Intrusion Prevention System)** | Detects and blocks suspicious activity.      |

## 🛡️ Defensive Perspective

This module is the foundation of all defensive network security. Key defensive takeaways include:

- **Understanding the OSI/TCP/IP models** allows defenders to pinpoint where an attack is occurring (Layer 2 ARP spoofing, Layer 3 IP spoofing, Layer 4 port scanning, Layer 7 application attacks).
- **Firewalls, IDS, and IPS** are the core tools for network defense. Knowing how they work is essential for configuring them effectively.
- **DHCP and DNS** are common attack vectors. Rogue DHCP servers can redirect traffic, and DNS poisoning can redirect users to malicious sites. Defenders must monitor these services.
- **NAT and PAT** provide a layer of obscurity but are not security controls. They must be combined with firewalls and other defenses.
- **The CIA Triad** guides all network security decisions — from encryption (confidentiality) to backups (availability).
- **ARP** is vulnerable to spoofing attacks. Defenders can use Dynamic ARP Inspection (DAI) to mitigate this.

- Networking is the backbone of cybersecurity. Without a strong understanding of how data flows, you cannot secure it.
- Every security control (firewall, IDS, IPS) operates at specific layers of the network model.
- Many attacks (ARP spoofing, DNS poisoning, DHCP starvation) exploit fundamental network protocols.
- Understanding how networks are supposed to work is the prerequisite for detecting when they are being abused.
