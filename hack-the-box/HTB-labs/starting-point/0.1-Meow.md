## 📌 Overview

Meow is the first machine in the Hack The Box Starting Point series. It is designed as an introduction to the platform and walks the user through the entire penetration testing workflow: connecting to the VPN, scanning a target, discovering a vulnerable service, exploiting it, and retrieving the flag. The machine focuses on beginner enumeration techniques and demonstrates the exploitation of a misconfigured Telnet service that allows the `root` user to log in without a password.

## 🎯 Objectives

- Connect to the Hack The Box network via OpenVPN.
- Perform basic network reconnaissance with Nmap.
- Identify open ports and running services.
- Exploit a misconfigured Telnet service using default credentials.
- Retrieve the root flag.

## 🧰 Tools Used

- **OpenVPN:** To connect to the Hack The Box internal network.
- **Nmap:** For port scanning and service enumeration.
- **Telnet:** To connect to the vulnerable service.
- **Basic Linux Commands:** `ls`, `cd`, `cat`.

## 🕵️‍♂️ Hands-On: Penetration Testing Meow

### 🔎 Reconnaissance

#### Target Info

```text
IP: 10.129.X.X (Assigned by HTB)
Hostname: meow
```

#### Commands Executed

```bash
# Basic port scan with service detection
nmap -A -T4 10.129.X.X
```

#### Results

```text
PORT   STATE SERVICE VERSION
23/tcp open  telnet  Linux telnetd
```

**Analysis:**

- **Port 23/tcp** is open and running a **Linux telnetd** service.
- Telnet is an unencrypted protocol that is often misconfigured in legacy or lab environments.
- The service version suggests it is a Linux-based Telnet daemon.

### 🔍 Enumeration

**Port 23 (Telnet)**

- **Service:** Telnet
- **Version:** Linux telnetd
- **Findings:** Telnet is an outdated protocol that transmits data — including credentials — in plaintext. In this case, the service is misconfigured to allow the `root` user to log in without a password.

### 💥 Exploitation / Validation

The vulnerability lies in a misconfigured Telnet service that allows the `root` user to authenticate without providing a password.

**Step 1: Connect via Telnet**

```bash
telnet 10.129.X.X
```

**Step 2: Attempt Login**
When prompted for a login, use the username `root` and press Enter without entering a password.

```text
meow login: root
Welcome to Linux (Ubuntu ...)
root@meow:~#
```

The connection succeeds, and we are dropped into a root shell. This is a critical misconfiguration — the highest-privileged account on the system is accessible with no authentication.

**Step 3: Retrieve the Flag**

```bash
ls
cat flag.txt
```

The flag is stored in the root user's home directory.

## 🛡️ Defensive Perspective

- **Detection:** Telnet authentication attempts (especially successful ones) generate logs on the target system. A defender monitoring authentication logs would see a root login from an unknown IP with no password prompt. Network monitoring tools would also detect Telnet traffic on port 23, which should be flagged as suspicious in any modern environment.
- **Prevention:**
    - **Disable Telnet entirely.** Replace it with SSH, which encrypts all traffic and supports key-based authentication.
    - **Enforce strong authentication.** No service should ever allow login without a password.
    - **Principle of Least Privilege:** The `root` account should never be directly accessible over the network.
    - **Network Segmentation:** Restrict access to management protocols (like Telnet or SSH) to trusted internal networks only.

## 🧠 What I Learned

- The importance of **network enumeration** — a simple Nmap scan revealed the entire attack surface.
- Telnet is an insecure, legacy protocol that should never be used in production.
- Misconfigurations (like passwordless root login) are just as dangerous as software vulnerabilities.
- The importance of **checking default credentials** — a common attack vector in real-world engagements.
- How to connect to Hack The Box via OpenVPN and interact with a target machine.

## 📚 Key Takeaways

- **Enumerate first, exploit second.** A disciplined approach to reconnaissance always pays off.
- **Misconfigurations are vulnerabilities.** The most secure software in the world can be compromised by a single configuration mistake.
- **Legacy protocols are dangerous.** Telnet, FTP, and other unencrypted protocols should be replaced with secure alternatives (SSH, SFTP, etc.).
- **Starting Point machines are guided learning tools.** They are designed to teach the methodology, not to be challenging puzzles.
