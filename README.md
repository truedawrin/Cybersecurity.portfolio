## 🔐 Ethics & Scope

All offensive security work in this repository is intended for:

- Systems I own.

- Targets for which I have explicit authorization.

I do **not** use these techniques against systems without permission.

## 📊 Portfolio Evidence Standard

Every serious project or write-up should aim to contain:

1. **Objective** — what I was trying to learn or solve.
2. **Environment** — OS, VM, tools, and scope.
3. **Methodology** — how I approached the problem.
4. **Evidence** — screenshots, outputs, logs, diagrams, or code.
5. **Analysis** — why the result happened.
6. **Security impact** — why it matters.
7. **Remediation / defense** — how it can be prevented or detected.
8. **Lessons learned** — what I would do better next time.
