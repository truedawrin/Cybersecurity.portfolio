# 🟣 Hack The Box Write-Ups

This section is for Hack The Box machines and challenges completed through authorized platform environments.

## Machine methodology

```text
Reconnaissance
     ↓
Enumeration
     ↓
Service / Web Analysis
     ↓
Initial Access
     ↓
Foothold Validation
     ↓
Privilege Escalation
     ↓
Evidence + Documentation
     ↓
Remediation / Lessons Learned
```

## Structure

```text
hackthebox/
├── machines/
│   ├── easy/
│   ├── medium/
│   └── hard/
└── challenges/
```

Each completed machine should have a focused write-up rather than a command dump.
