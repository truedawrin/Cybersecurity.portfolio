# 🖥️ Virtualization Lab

Virtualization is the foundation of my safe security practice environment.

## Goals

- Run Kali Linux safely
- Build intentionally vulnerable systems
- Practice network segmentation
- Use snapshots for repeatability
- Learn how host/guest networking works
- Keep offensive experiments isolated

## Hardware Context

Current learning machine:

- CPU: AMD Ryzen 5 5500U with Radeon Graphics
- RAM: approximately 7.1 GiB available to the operating environment
- Disk: approximately 238.5 GB

The lab is designed around lightweight VMs because available memory is limited.
