# 🟦 SOC Lab

Planned defensive-security lab for learning how a security analyst detects, investigates, and documents suspicious activity.

## Planned components

- Linux and Windows endpoints
- Centralized logs
- Basic SIEM workflow
- Detection rules
- Investigation timelines
- Network evidence
- Incident reports

## Investigation workflow

```text
Alert
  ↓
Validate
  ↓
Collect Evidence
  ↓
Build Timeline
  ↓
Identify Indicators
  ↓
Assess Impact
  ↓
Contain / Recommend
  ↓
Document
```
