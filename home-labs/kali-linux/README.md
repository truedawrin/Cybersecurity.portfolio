# 🐉 Kali Linux Lab

## Purpose

An isolated virtual environment for learning offensive-security tooling without touching unauthorized systems.

## Current Environment

- Host OS: CachyOS Linux
- Desktop: KDE Plasma
- Virtualization: VirtualBox
- Guest: Kali Linux

## Planned Practice

- Nmap reconnaissance
- Service enumeration
- Web testing in deliberately vulnerable labs
- Traffic analysis with Wireshark
- Burp Suite practice
- Privilege escalation labs
- CTF methodology

## Safety

Keep offensive testing inside lab/CTF environments and snapshot VMs before major changes.
