## 📌 Overview

Part 2 of the Windows Fundamentals series. The official room description states: "In part 2 of the Windows Fundamentals module, discover more about System Configuration, UAC Settings, Resource Monitoring, the Windows Registry, and more…"

## 🎯 Objectives

- Explore advanced system configuration and management tools.
- Understand the Windows Registry.
- Learn about resource monitoring and system information tools.

## 🧰 Tools Used

- **System Configuration (`msconfig`):** For managing system startup, services, and tools.
- **Computer Management (`compmgmt.msc`):** A central console for managing system tools like Task Scheduler and Shared Folders.
- **System Information (`msinfo32.exe`):** A tool for viewing detailed system information.
- **Windows Registry (`regedit.exe`):** The central hierarchical database for Windows settings.

## 🛡️ Defensive Perspective

Advanced knowledge of Windows tools is essential for both attackers and defenders. Defenders use these tools to audit system configurations, monitor scheduled tasks for persistence, and inspect shared folders for unauthorized access. Understanding the Registry is critical, as it is a prime target for malware persistence.

## 🧠 What I Learned

- How to use `msconfig` to access and manage a wide range of system tools.
- How to use `compmgmt.msc` to view scheduled tasks and shared folders.
- The importance of the Windows Registry as a central configuration database.
- How to gather detailed system information with `msinfo32.exe`.

## 📚 Key Takeaways

- Windows provides a rich set of built-in tools for deep system administration.
- These tools are dual-use: they are essential for defenders to audit systems, but also for attackers to understand and manipulate a target.
- Understanding these tools is fundamental to both offensive and defensive Windows security.
