## 📌 Overview

The first part of the Linux Fundamentals series. The official room description states: "Embark on the journey of learning the fundamentals of Linux. Learn to run some of the first essential commands on an interactive terminal."

## 🎯 Objectives

- Understand the background and history of Linux.
- Interact with a Linux machine and run basic commands.
- Learn to navigate the file system.
- Search for files using the command line.

## 🧰 Tools Used

- **Terminal:** The command-line interface for interacting with the system.
- **Basic Linux Commands:** `echo`, `whoami`, `ls`, `cd`, `pwd`, `cat`, `find`, `grep`.

```bash
# Basic navigation

find / -name "*.txt"
grep "flag" file.txt
```

#### Results

Successfully navigated the file system and located a hidden text file containing a flag by using `find` and `grep`.

### 🔍 Enumeration

The "enumeration" in this room is learning to explore the Linux file system. Key activities included:

- **Interacting with the Filesystem:** Navigating the directory tree using `ls` and `cd`.
- **Searching for Files:** Using `find` and `grep` to locate files and search their contents.
- **Shell Operators:** Learning how to use `>` and `>>` to redirect output into files, and `&&` to run multiple commands.

## 🛡️ Defensive Perspective

A strong understanding of the Linux file system and command line is essential for any defensive analyst. Most servers on the internet run Linux. To investigate a compromised Linux server, you need to know how to navigate its file system, find configuration files, and search logs for malicious activity.

## 🧠 What I Learned

- The history of Linux and its various distributions (like Ubuntu). Linux was first released in 1991.
- How to run basic commands like `echo`, `whoami`, `ls`, `cd`, `pwd`, and `cat`.
- How to use `find` to search for files by name and `grep` to search inside files.
- How to use shell operators `>` (overwrite) and `>>` (append).

## 📚 Key Takeaways

- Linux is a powerful, lightweight, and ubiquitous operating system.
- The command line is the primary interface for managing Linux systems.
- Mastering basic commands for file system navigation and searching is the first step toward Linux proficiency.
