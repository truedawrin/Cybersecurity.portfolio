## 📌 Overview

This room begins the journey into the Windows operating system. It covers the Windows desktop, the NTFS file system, User Account Control (UAC), the Control Panel, and the Task Manager.

## 🎯 Objectives

- Understand the different editions of Windows.
- Learn the basics of the Windows desktop and GUI.
- Understand the NTFS file system and its permissions.
- Learn about user accounts, UAC, and core system tools.

## 🧰 Tools Used

- **Windows Desktop & GUI:** The graphical interface.
- **File System:** NTFS (New Technology File System).
- **Key Tools:** Task Manager, Control Panel, Settings, `lusrmgr.msc` (Local Users and Groups).

## 🛡️ Defensive Perspective

Understanding the Windows file system (NTFS), user accounts, and UAC is critical for defending a Windows environment. These are the fundamental building blocks of Windows security. Knowing how permissions work and how user accounts are structured is essential for detecting misconfigurations or unauthorized access.

## 🧠 What I Learned

- The difference between Windows Home and Pro editions (BitLocker is Pro-only).
- The meaning of NTFS (New Technology File System) and the purpose of the `%windir%` environment variable.
- How to find user accounts and groups using `lusrmgr.msc`.
- The purpose of User Account Control (UAC) as a security feature.
- How to use the Task Manager (Ctrl+Shift+Esc) to view running processes and their PIDs.

## 📚 Key Takeaways

- Windows is a complex operating system with many built-in security features.
- The NTFS file system provides a robust foundation for permissions and security.
- UAC is a key defense mechanism that prevents unauthorized changes to the system.
