## 📌 Overview

This room focuses on one of the most important skills in cybersecurity: the ability to find the right information quickly and accurately. The room teaches how to evaluate sources, use advanced search engine operators, and leverage specialized resources for technical research.

## 🎯 Objectives

- Learn how to evaluate the credibility of online information.
- Use advanced search engine operators for more effective queries.
- Explore specialized search engines and technical documentation.

## 🧰 Tools Used

- Search Engines (Google, Bing)
- Advanced Search Operators (`site:`, `filetype:`, `-keyword`)
- Specialized Search Platforms (Shodan, Censys, PublicWWW, VirusTotal)
- CVE Databases (MITRE, NVD, Exploit-DB)

## 🕵️‍♂️ Hands-On: OSINT

_(Theory Room - No practical exploitation)_

### 🔎 Reconnaissance

This entire room is about reconnaissance through information gathering. The "target" is knowledge itself. The room covers evaluation of search results, advanced search operators, and specialized search engines.

### 🔍 Enumeration

The room enumerates various information sources and search techniques. Key concepts include:

- **Evaluation of Search Results:** Consider the source, credibility, timeliness, relevance, and authority. Quality matters more than quantity.
- **Advanced Search Operators:** Using operators like `site:tryhackme.com success stories` to narrow down search results to a specific domain.
- **Specialized Search Engines:** Using tools like Shodan (finds internet-exposed devices/services), Censys (certificate & service data), and PublicWWW (search websites by source code).

### 💥 Exploitation / Validation

Not applicable. The goal is to find information, not to exploit a system.

## 🛡️ Defensive Perspective

Good search skills are crucial for defenders. A SOC analyst needs to quickly find information about a suspicious IP, a file hash, or a new vulnerability. Threat intelligence analysts use these skills to gather information about threat actors. This room is a core skill for any defensive role.

## 🧠 What I Learned

- How to critically evaluate information found online rather than accepting it at face value.
- How to use advanced search operators like `site:`, `filetype:`, and `-keyword`.
- That there are specialized search engines for specific cybersecurity tasks (Shodan, Censys, PublicWWW).
- How to search for CVE vulnerabilities and technical documentation.

## 📚 Key Takeaways

- Effective search skills are a force multiplier for any cybersecurity professional.
- Always verify the source and objectivity of information.
- Specialized tools and operators can turn a huge amount of information into a manageable, targeted set of results.
