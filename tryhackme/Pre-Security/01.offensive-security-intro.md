## 📌 Overview

An introductory room that provides a hands-on, legal experience of hacking a simulated website. The official room description states: "Hack your first website (legally in a safe environment) and experience an ethical hacker's job."

## 🎯 Objectives

- Understand the core concept of Offensive Security.
- Perform legal reconnaissance and exploitation against a simulated target (FakeBank).
- Experience the workflow of an ethical hacker using Gobuster for directory enumeration.

## 🧰 Tools Used

- **Gobuster:** A tool used for directory and file enumeration on web servers. It was used to discover the hidden `/bank-transfer` directory.

### 💥 Exploitation / Validation

The vulnerability lies in a web application that allows unauthorized fund transfers. By navigating to the discovered `/bank-transfer` directory, I was able to perform a simulated bank transfer to another account (Send from: 2276, Send to: 8881, Amount: 2000 USD), demonstrating a business logic flaw. This was validated in a safe lab environment as confirmed by the room walkthrough.

## 🛡️ Defensive Perspective

- **Detection:** Web server logs would show requests to unusual or sensitive directories like `/bank-transfer`. Monitoring for access to admin or financial endpoints is key.
- **Prevention:** Implement proper authorization checks on all sensitive functions. Ensure that a user cannot perform actions they are not permitted to do, such as transferring funds from an account they don't own. Directory listing should be disabled to prevent easy discovery of hidden paths.

## 🧠 What I Learned

- The fundamental difference between offensive security and malicious hacking.
- How to use Gobuster for directory enumeration.
- The importance of checking for hidden pages and directories in web applications.

## 📚 Key Takeaways

- Offensive security involves legally simulating attacks to find vulnerabilities before malicious actors do.
- Even simple web applications can have hidden functionality that is not linked in the main navigation.
- Tools like Gobuster are essential for mapping the attack surface of a web application.
