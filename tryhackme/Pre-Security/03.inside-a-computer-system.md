### 🔍 Enumeration

This room focused on enumerating the physical components of a computer system and the boot sequence.

**1. Core Components (Human Body Analogy)**

| Component             | Human Analogy             | Function                                                                                                           |
| :-------------------- | :------------------------ | :----------------------------------------------------------------------------------------------------------------- |
| **Motherboard**       | Skeleton & Nervous System | Holds all components and connects them. Contains CPU socket, RAM slots, expansion slots, and ports.                |
| **CPU**               | Brain                     | Processes instructions. Modern CPUs have multiple cores for parallel execution. Connects via the CPU socket.       |
| **RAM**               | Short-term Memory         | Holds data the CPU needs quick access to. Volatile — contents lost when power is removed. Modern types: DDR5/DDR6. |
| **Storage (HDD/SSD)** | Long-term Memory          | Holds data permanently. Survives power loss.                                                                       |
| **PSU**               | Heart & Lungs             | Supplies power to all components.                                                                                  |
| **GPU**               | Visual Cortex             | Handles graphics rendering.                                                                                        |

**2. The Boot Process — "What Happens When You Press the Start Button?"**

| Step  | Action                    | Analogy                                                                                         |
| :---- | :------------------------ | :---------------------------------------------------------------------------------------------- |
| **1** | Press Power Button        | Signal sent to PSU; power flows. Like waking up and receiving oxygen.                           |
| **2** | Firmware Starts           | UEFI (or BIOS) initializes components. Like the body starting up but brain not yet conscious.   |
| **3** | POST (Power-On Self Test) | Checks every component is present and working. Like a morning check to see if everything is OK. |
| **4** | Boot Device Selection     | Selects a boot device (disk, USB, network).                                                     |
| **5** | Bootloader                | Loads the operating system into RAM. Control handed to the OS.                                  |

**3. Key Components Summary**

- **Motherboard:** The central hub — every other component plugs into it.
- **CPU:** The processor — executes instructions. Multiple cores handle tasks in parallel.
- **RAM:** Volatile working memory — fast but cleared on power loss.
- **Storage:** Non-volatile long-term memory — HDD (spinning disk) or SSD (flash memory).
- **PSU:** Power supply — converts AC to DC for components.
- **GPU:** Graphics processor — handles visual output.

## 🛡️ Defensive Perspective

- **Boot process security:** The boot process is sometimes targeted by hackers. A compromised firmware (UEFI/BIOS) can persist across OS reinstalls. This is why Secure Boot and firmware integrity checks exist.
- **Hardware vulnerabilities:** Firmware-level attacks (e.g., rootkits in UEFI) are extremely difficult to detect and remove.
- **Physical security:** If an attacker has physical access to a machine, they can potentially tamper with the boot process, install hardware keyloggers, or boot from external media. Physical security is the foundation of all other security.

## 🧠 What I Learned

- The core components of a computer system and their functions.
- How the motherboard connects all components.
- The boot process: Power → Firmware (UEFI) → POST → Boot Device → Bootloader → OS.
- The difference between volatile memory (RAM) and non-volatile storage (HDD/SSD).
- That the boot process is a potential attack surface.

## 📚 Key Takeaways

- Understanding hardware is a prerequisite for understanding security. You cannot defend what you do not understand.
- The boot process is a critical security boundary — firmware attacks can persist across OS reinstalls.
- The human body analogy makes the relationships between components intuitive.
