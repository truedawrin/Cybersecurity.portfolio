# 🔵 Security Analysis Methodology

## 1. Triage

Understand the alert and determine whether it is likely benign, suspicious, or malicious.

## 2. Scope the event

Identify affected hosts, users, applications, timestamps, and relevant logs.

## 3. Build a timeline

Order observations by time and identify the sequence of events.

## 4. Extract indicators

Record suspicious IPs, domains, filenames, hashes, processes, accounts, and other useful artifacts.

## 5. Determine impact

Estimate what was accessed, changed, or potentially compromised.

## 6. Recommend action

Containment, eradication, recovery, and detection improvements should be explicit.

## 7. Document

A strong investigation should be reproducible by another analyst.
