# 🔎 IP Sweep

A Bash-based network discovery utility that checks hosts in an authorized subnet and reports responsive systems.

## Objective

Build a small practical tool while reinforcing IP addressing, loops, shell conditionals, exit status, and network reconnaissance concepts.

## Skills Demonstrated

- Bash scripting
- IPv4 addressing
- Loops and conditionals
- Command-line automation
- Basic network reconnaissance
- Output formatting

## Security Relevance

Host discovery is commonly an early step in an authorized penetration test. The important skill is not simply knowing a command, but understanding what the command is testing, what the result means, and what limitations exist.

## Ethical Scope

Use only on networks you own or are explicitly authorized to test.

# Script
```bash
!/usr/bin/env bash

echo "enter an ip address to scan its subnet:"
read ip

if [ "$ip" == "" ]
                then
                echo "No ip entered"
                echo "Syntax: ./ipsweep.sh (ip address)"
else
     for Host in `seq 1 254`; do
     ping -c 1 $ip.$Host | grep "64 bytes" | cut -d " " -f 4 | tr -d ":" &
     ping -c 1 $ip.$Host | grep "64 bytes" | cut -d " " -f 4 | tr -d ":" & >> ip-logs.txt
done
 echo " --Scan completed--"
 echo " --all logs has been sent to the ip-logs.txt file-- "
fi


```
